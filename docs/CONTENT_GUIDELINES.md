# 애니멀픽 콘텐츠 가이드 (초안)

## 매거진형 캐러셀: 기존 방향과 구별하기
- **해야 할 것:** 실제 검증된 뉴스/화제, 동물·반려동물·흥미로운 사건을 공감/호기심/놀라움의 각도로 편집.
- **아닌 것:** AI가 가상 인물과 가상 사건을 만들어내는 동화·감동 스토리 계정.
- 참조 계정의 디자인은 성공 원인을 학습하되 복제 금지. 실제 레퍼런스 게시물 시각 분석 후 템플릿 정식 확정.

## 현재 형식 (2026-11-22 사용자 확정)
- 캐러셀 기본 2장: 1장 = 사진 위 표지 제목, 2장 = 같은 사진(글자 없음, 저작자 표기만).
- 이야기의 핵심 사진(예: 웜뱃의 네모난 똥)이 실제로 있으면 3장째부터 글자 없는 사진으로 추가. 없으면 억지로 채우지 않음.
- 표지 사진은 위키미디어 실제 사진 우선. 사진 사이트 사진은 AI 생성 여부를 원본 페이지에서 확인.
- 이야기는 모두 캡션: 합니다체(-입니다/-합니다), 첫 줄 궁금증 한 문장, 짧은 문단 4~7개(문단당 1~2문장, 빈 줄로 구분), 쉬운 말, 400~900자, 마지막 줄 출처.
- 표지 제목: 22자 이내 2줄, 명사형 또는 합니다체로 끝냄('-다' 금지).

## 이전 제안 템플릿 (폐기)
- 1080×1350px (4:5) 표지 + 설명 2~5장 + 결말/출처/참여 유도 1장.
- 표지: 실제 대상/장면 + 짧은 강한 제목(자체 작성, 과장·허위 금지).
- 중간: 맥락, 이해할 만한 사실, 핵심 반전/정보.
- 마지막: 확인된 결말 또는 간결한 질문. 인위적 댓글 유도/과도한 낚시 지양.
- 톤: 깔끔한 매거진형, 과한 스티커/장식보다 사진·제목 중심.

## 필수 검수 체크
- [ ] 날짜/출처가 확인되는가?
- [ ] 영상이 AI 생성인지, 실존 사건인지 검증했는가?
- [ ] 이미지·음원 등 사용 권리가 있는가?
- [ ] 원본 사진/본문/레이아웃을 거의 그대로 재게시하지 않았는가?
- [ ] 제목과 본문이 사실을 과장하거나 오해시키지 않는가?
- [ ] 게시물 정보의 라이선스·출처와 AI 생성 표시를 기록했는가?
- [ ] 검수가 막힌 후보는 자동 게시 큐에 들어가지 않는가?

## 성과 분석
- 게시물 절대 성과뿐 아니라 기준선 대비 차이, 업로드 후 경과 시간, 유효 비교 집단 고려.
- 자사 계정의 저장/공유/도달 등은 승인된 인사이트에서 수집 가능 여부 확인.
- 타인 계정의 결측 데이터를 상상해서 채우지 않음.
