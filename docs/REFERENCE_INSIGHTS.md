## 크게 터진 유형 (중앙값의 10~130배)
1. **모음형**: 주제 하나 + 서로 다른 놀라운 사진 여러 장. 예) '12가지 증거', 기술 발전으로 사라진 개들,
   거대 생물들이 지배하던 시절, 현실에 오류가 생긴 듯한 장면들.
2. **장면이 그려지는 순간**: 퇴근 후 고양이가 거꾸로 매달려 있었다 / 눈을 보며 행복한 표정의 돼지.
3. **결과를 약속하는 제목**: 숫자, '이걸 보여줘라', '공개', '포착'.

## 반응이 없던 유형 (중앙값의 0.1배 이하)
- 사전식 사실 소개(한 곳에만 사는 분홍 민달팽이), 기관·장비·시설 소식(탐사차 먼지 분석, 대형 시설 건설),
  밋밋한 이색 행사(오리 패션쇼는 petmorrow 에서 0.06배).

## 반영 (코드)
- `writer.HEADLINE_RULES` / `CAPTION_HOOK_RULES`: 주인공·장면이 보이는 제목, 작은따옴표 강조, 결과 약속, 비유·'~의 정체' 금지,
  퀴즈형 첫 줄·백과사전식 나열 금지, 제목 후보 5개.
- 모음형(`format: list`): 기획 → 항목별 위키백과 확인 → 작성, 사진에 번호만, 캡션 '① 이름: 설명'.
- 소싱 채점(`sources.SCORE_SYSTEM`): 위 '높게/낮게' 기준, 상시 소재 절반 이상을 모음형으로.

다음 분석 때는 같은 스크립트로 다시 뽑아 변화를 비교한다 (게시 성과 수집 단계와 연결).
