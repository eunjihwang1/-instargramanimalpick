# 원 대화 인수인계 — 사용자 의도 및 결정

## 브랜드 / 운영 목표
- Instagram 매거진 신규 계정 **애니멀픽 (AnimalPick)** 운영. 사용자 제공 프로필 스크린샷상 핸들은 `animal..pickk`로 보이나 **직접 API 확인 전 잠정**.
- 프로필: 검은 텍스트 `ANIMAL PICK` 로고, 계정 설명은 세상의 흥미로운 소식·뉴스를 다루는 내용.
- 처음에는 동물/흥미로운 소식 중심. 그러나 **동물만으로 제한된 AI 허구 스토리 계정이 아님**. 실제 이슈·사건·흥미로운 화제의 소재를 편집하는 한국어 매거진형 카드뉴스/캐러셀 계정을 지향.
- 최종 목표: AI가 참고 계정/뉴스/허용된 공개 소스를 분석해 하루 **10개 정도 캐러셀 콘텐츠**를 기획·제작·검수·예약 게시하며 인사이트를 토대로 개선.
- 궁극적 수익화는 한국 Instagram **보너스(초대제)** 고려. 조회수 조건 및 수익 단가는 최신 공식 계정 화면으로 확인해야 하며 초대/수익 보장 안 됨.

## 사용자가 명시한 두 가지 콘텐츠 공급 경로
**A — 성공한 기존 게시물 패턴의 새로운 콘텐츠화**
  1) 사용자가 제공한 인스타그램 참고 계정을 많이 저장.
  2) 공개 지표가 잘 나온 게시물 선별, 같은 계정의 평균과 비교.
  3) 왜 반응이 높았는지 소재·첫 장·후킹·댓글 유발·이미지 등 분석.
  4) 검증된 사실/소재를 토대로 사용 권리를 확보한 이미지와 독창적인 디자인·문구로 *재창작*.

**B — 신선한 이슈 신규 제작**
  1) 뉴스 RSS/공식 출처/API/허용된 커뮤니티에서 화제 후보 발견.
  2) 진위와 시점, 국내 관심 가능성, 이미 인스타에 지나치게 확산되었는지 분석(알 수 없을 땐 미확인 표기).
  3) 사용 가능한 이미지 확보 + 새로운 한국어 매거진 캐러셀 기획/제작.

두 경로 모두 구현하고 비율은 초기 **예시 A 6개 + B 4개**로 논의. 검증된 최적값 아님.

## 기존 기획에서 사용자와 수정한 방향
- 사용자는 AI가 그린 창작 감동 스토리/옛 추억 위주가 아니라고 분명히 정정함.
- 진짜 원하는 것은 `@heodukgoo`, `@popo.scope`, `@issue.unni`, `@nugget.today` 등처럼 **화제의 실제 소재를 발굴·큐레이션하는 인스타 매거진**.
- 주제가 흥미로운지, 감정 변화(궁금증/놀라움/귀여움/공감 등)가 있는지, 공유·댓글 유발력이 있는지가 중요.
- AI 생성 이미지는 부족한 자료를 대체할 수 있으나 합성·창작과 실제 사진/사실을 혼동시키면 안 됨.
- 이미지 스타일은 기본적으로 깔끔하고 읽기 쉬운 매거진 톤. 템플릿은 실제 레퍼런스 실물 게시물 분석 후 확정.

## 성공 원인 분석 지침
- 절대적인 좋아요/조회수뿐 아니라, 같은 계정·비슷한 게시 시점의 기준선과 비교.
- 표지 첫 장: 무엇을 보여주며 몇 글자로 후킹하는가?
- 콘텐츠: 감정, 의외성, 뉴스성, 이미지 자체의 강도, 참여할 이유.
- 실제 공개 지표와 모델이 추론한 정성 가설을 분리 저장.
- 댓글/공유/저장은 성과 지표로 중요하나 **다른 계정의 공유·저장 등 비공개 Insights 접근은 가정하지 않는다**.
- 통계가 약하면 조회수 예측을 확정값으로 표현하지 않는다.

## 콘텐츠/계정 안전 원칙
- 기사와 남의 콘텐츠를 **바로 복사 또는 사진·캡션만 약간 바꿔 게시**하지 않음.
- 출처를 표시해도 이미지 저작권/재사용 권리가 생기지 않는다. 권리 미확인 자료는 게시하지 않음.
- 실제 사건·동물인지 확인하며 AI 합성임을 숨기지 않음.
- 스팸성 반복 게시, 비인가 웹 크롤링·계정 자동화 회피.

## 장기 그림
자신이 수동 편집을 계속 하지 않아도 AI가 [소재 탐색 → 선정 → 사실 확인 → 이미지 권리 점검 → 캐러셀 제작 → 승인/발행 → 성과 분석 → 다음 기획]을 반복하는 시스템. 사람이 개입해야 할 불확실 사례는 자동 보류.
